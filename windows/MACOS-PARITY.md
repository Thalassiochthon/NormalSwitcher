# Сверка Windows с macOS 1.2.0r

Эталон macOS — тег [v1.2.0r](https://github.com/Thalassiochthon/NormalSwitcher/tree/v1.2.0r/macos). Основа Windows — [PR №2](https://github.com/Thalassiochthon/NormalSwitcher/pull/2). Сверка относится к пользовательским действиям. Нативные механизмы ввода, трея и обновления остаются платформенными.

| Сценарий на Mac | Состояние Windows |
| --- | --- |
| Хранить снимки и скопированные изображения | Добавлена смешанная история. Текстовые записи с прошлых версий читаются. Снимки имеют превью, вставляются в исходном размере и сохраняются зашифрованными при включённом сохранении истории. Лимит изображений 0–50, по умолчанию 10 |
| Просматривать длинные записи | Добавлен предпросмотр полного текста и снимка. Окно тянется и запоминает размер |
| Показать раскладку и исправить слово стрелкой у курсора | Добавлена полупрозрачная плашка с нативной кареткой и запасной позицией внутри активного окна при печати. Перед заменой проверяется неизменность поля и исходного текста |
| Запомнить слово через стрелку | Исправленное написание сохраняется в «Всегда конвертировать». Есть отдельная настройка. Правильно набранное сохранённое слово остаётся в своей раскладке |
| Быстрые задачи и создание из истории или текущего буфера | Реализовано в предыдущей Windows-бете, с отдельным шифрованным хранилищем и ручным добавлением |
| Возврат после обновления и бета-канал | В Windows есть отдельный процесс установки, проверка хеша и бета-канал. Присутствие версии в канале зависит от публикации |
| Ручное исправление, отмена, исключения, сочетания и звуки | Уже реализованы в Windows. Однозначность выбора цели при трёх и более раскладках проверяется отдельно. Windows использует установленные словари Windows, Mac — свои словари |
| Двойной звук автоисправления | Добавлен отдельный переключатель в разделе «Индикаторы» |
| Языки интерфейса | Mac включает 16 локализаций. В Windows сейчас русский и английский. Перенос остальных переводов требует проверок строк, специфичных для Windows |
| Надёжность ввода и статус автоисправления | Windows проверяет фокус и текст через Win32 или UI Automation. Поддержка конкретного поля зависит от доступности его текста. Проверки для Паолы — в [PAOLA-QA.md](PAOLA-QA.md) |

## Проверка на установленной бете

1. Включить запись истории, скопировать текст, область экрана через Win+Shift+S и картинку из браузера. Перезапустить приложение с включённым сохранением истории. Открыть превью, вставить снимок обратно, проверить разрешение и убрать картинки из истории лимитом 0.
2. Включить плашку у курсора и запоминание стрелкой. В английской раскладке набрать `kf,e,f`, нажать ↻, затем повторить ввод слова и пробела. Проверить наличие «лабуба» в «Всегда конвертировать». Повторить с выключенным запоминанием и проверить область около кнопки отправки в браузере.
3. Проверить защищённое поле, смену фокуса перед нажатием, ввод без UI Automation, два монитора с разным DPI и вставку картинки в собственное поле приложения. При смене поля нельзя ни заменить текст, ни вставить запись в другое окно.
