# NormalSwitcher для Windows. Аудит и повторное тестирование

Аудит относится к опубликованной Windows Preview 0.2.6 и к предрелизной ветке `windows/macos-parity-audit` с задачами. Код для повторного тестирования подготовлен поверх коммита `acd2b55`. Версия сборки, на которой Паола увидела ошибку задач, неизвестна. [Отзыв Паолы в Miro](https://miro.com/app/board/uXjVEMbINYc=/?moveToWidget=3458764691255717687)

## Технический чек-лист

| --- | --- | --- | --- |
| P0 | После входа приходится запускать вручную | Автозапуск регистрируется в HKCU Run. Предрелизная ветка уже восстанавливает путь к перемещённой копии при ручном запуске. Отказ трея или клавиатурного хука при старте оставлял работающий процесс без значка или исправления | Добавлены повтор регистрации значка и ограниченный повтор установки хука, проверка записи Run и отдельный тихий запуск с `--startup`. Проверить свежий вход и перезагрузку при обычных правах. Windows может запускать элементы Run с задержкой |
| P0 | Исправление отсутствует в некоторых приложениях | Автоисправление требует прочитать точный текст у курсора через Win32 или UI Automation. Предрелизная ветка уже проверяет фокус и текст в составных редакторах. При повышенных правах чужого приложения Windows может блокировать SendInput | Добавлены причины пропуска в диагностике и тест составного редактора. Для сбоя сохранить название приложения, тип поля, способ исправления, привилегии и причину из журнала. Исправлять воспроизводимые сбои без снятия проверки поля |
| P0 | Ошибка короткого названия задачи | В предрелизном коде 120 графем — включительный максимум. Возможны разные ошибки проверки и записи. Исходное сообщение и точная сборка неизвестны | Добавлена заметная кнопка «Новая задача» и отдельные сообщения для пустого и слишком длинного названия. Регрессия проверяет сохранение короткой задачи через окно, а также границы 1, 119, 120 и 121 |

Явно выбранная пара ограничивает цели. При неопределённом словарном результате или нескольких подходящих результатах замены нет. Ручное исправление сейчас берёт первый доступный вариант | Уточнена подсказка в настройках и добавлен тест автоматических целей и явной пары. Проверить RU/EN/ES на реальных раскладках и словаре Windows. Выбор назначения ручного исправления для 3+ раскладок остаётся P1 |

## Матрица для Паолы

Перед тестом записать версию NormalSwitcher, версию Windows, названия раскладок, способ установки и проверяемые приложения. Настроить одиночный Ctrl по привычному сценарию и включить автоисправление по пробелу.

| Сценарий | Действие | Критерий |
| --- | --- | --- |
| Вход и перезагрузка | Включить автозапуск, проверить его статус в «Приложения → Автозагрузка» Windows. Выйти из учётной записи и войти, затем перезагрузить ПК. Повторить с выключенным автозапуском | При включённом состоянии после входа работает одна копия. Значок доступен в трее или его скрытой области. Ctrl и исправление работают. При выключении запуск не происходит |
| Проверенные поля | Chrome/Edge: адресная строка и обычное поле. Telegram Desktop: ввод сообщения. Проводник: переименование файла. Блокнот: обычный документ | Для каждого поля проверить одиночный Ctrl, ручную коррекцию и пробел по отдельности. При быстрой печати символы остаются на месте, корректное слово не меняется |
| Сложные поля | Приложение, где Паола увидела сбой. Для примера Photoshop — текстовый слой и обычное поле настроек. Отдельно проверить программу, запущенную с повышенными правами | Зафиксировать результат каждого режима и наличие доступного поля. После отказа текст остаётся целым. Повышенные права учитываются как ограничение при подтверждении |
| Безопасное поведение | Ввод в пароль, поле только для чтения, выделение и смена окна во время автоисправления | Ничего не стирается и не переносится в другое поле |
| Третий язык | Установить RU/EN/ES. Проверить цикл Ctrl. Для пробела оставить выбор раскладок «Автоматически» и набрать `рщдф` для «hola» и `ghbdtn` для «привет». Проверить, что «hola» в испанской раскладке сохраняется. Повторить с явной парой RU/EN | В цикле доступны все раскладки. В автоисправлении участвуют только допустимые однозначные цели. Если не сработало, записать какой словарь ES установлен, исходную раскладку и причину из журнала |
| Задача вручную | Трей → Задачи → Новая задача → «План» → Сохранить. Перезапустить. Повторить с пустым заголовком и длиннее 120 графем | «План» появился и сохранился после перезапуска. Сообщения пустого и длинного названия отличаются |
| Буфер и задачи | Скопировать многострочный текст → История → В задачи. Проверить тело задачи. Проверить сохранение по хоткею при отключённой истории и отмену добавления | Сохраняется полный текст, хотя в списке показано превью. Отмена удаляет только добавленную задачу. Очистка буфера не удаляет задачи |
| Обновление | Обновить установленную 0.2.6 тестовым установщиком поверх старой версии. Сверить раскладки, Ctrl, автоисправление, звук и историю | Пользовательские настройки и история сохранились, приложение перезапустилось один раз |

## Условия выпуска

- CI на Windows собирает x64 и ARM64 и проверяет тесты. Интеграционный прогон x64 использует Win32, WinForms и WPF, проверяет обновление, трей, сочетания и исправление. Он не воспроизводит настоящий вход в систему после перезагрузки.
- Паола подтверждает два цикла входа после перезагрузки, ручное создание короткой задачи и регрессию браузера, Telegram, Проводника и Ctrl.
- Для полей со сбоем указано точное приложение и известно, что исправлено, где не хватает данных приложения и что ограничивает Windows. Неясные сбои с потерей текста блокируют выпуск.
- Перевод, изменение размера окна и выбор цели ручного исправления при 3+ раскладках планируются отдельно после проверки P0.
